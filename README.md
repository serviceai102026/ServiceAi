# ServiceAI

موقع عربي RTL مبني باستخدام Next.js لمساعدة الباحثين عن عمل. تعمل أدوات الموقع ولوحة المقالات محليًا في المتصفح، بينما يستخدم مدير إعلانات AdSense Firebase Authentication وFirestore.

## التشغيل

1. ثبّت Node.js 20.9 أو أحدث.
2. شغّل `npm install`.
3. شغّل `npm run dev` وافتح `http://localhost:3000`.

يحتاج تشغيل الواجهة العامة محليًا إلى الحزم فقط. يتطلب تسجيل دخول مدير الإعلانات واتصاله بـ Firestore إعداد متغيرات Firebase في `.env.local` ونشر قواعد Firestore الموضحة أدناه.

## لوحة الإدارة المحلية

افتح `/admin/login`. بيانات الدخول الافتراضية هي `tahar@gmail.com` و`admin123`، ويمكن تغييرها من `/admin/credentials`. تتيح `/admin/pages` تعديل الصفحات الست في `data/pages.json`.

**تنبيه أمني:** هذا الدخول محلي وتجريبي فقط، وليس حماية حقيقية. بيانات المدير والجلسة موجودة في مساحة تخزين المتصفح ويمكن تجاوزها أو تعديلها من أدوات المطور. لا تستخدم هذا النمط لمعلومات حساسة أو موقع عام متعدد المستخدمين.

تعديل ملفات الصفحات عبر `/api/admin/pages` مفعّل في بيئة التطوير المحلية فقط، لأن نظام تسجيل الدخول المعتمد على المتصفح لا يمكن التحقق منه بأمان في API على خادم الإنتاج. بيانات ملفات JSON على خوادم الاستضافة ذات نظام الملفات المؤقت قد لا تبقى بعد إعادة النشر أو إعادة التشغيل.

## مدير Google AdSense

- تحكم في عرض الإعلانات من `config/ads.ts` دون استخدام Firebase: `enabled` يوقف الإعلانات بالكامل، و`showOnHomepage` و`showOnBlog` يتحكمان في الصفحات المعنية، و`hideOnPages` يستثني مسارات محددة.
- أدخل Publisher ID وأرقام الوحدات وفعّل المواضع الخمسة من `/admin/ads-manager` أو قسم Google AdSense في إعدادات الموقع. تُحفظ هذه القيم في `localStorage` تحت المفتاح `adsense_settings` دون Firebase.
- يجب إدخال Publisher ID ورقم الوحدة قبل تفعيل الموضع. لا تُحمّل مكتبة AdSense ولا تظهر الإعلانات حين تكون معطلة أو يكون المسار مستثنى.

## البيانات والحدود

- تحتوي `data/blogs.json` على 26 مقالًا جاهزًا للنشر (20 بالعربية و6 بالإنجليزية) مع صور محلية وبيانات SEO؛ تظهر هذه المقالات في المدونة إلى جانب مقالات المدير المحفوظة في المتصفح.
- المقالات المنشورة والمسودات، التصنيفات، هوية الموقع (الاسم والشعار النصي والوصف وبريد التواصل)، التذييل، إعدادات الموقع وروابط التواصل والإعلانات والسلايدر محفوظة محليًا لكل متصفح. يبدأ السلايدر بثلاث شرائح محلية قابلة للتعديل، ويعمل تلقائيًا.
- عناوين ومحتوى التواصل ومن نحن والأدوات والمدونة والخصوصية والشروط تُقرأ من `data/pages.json`. يُنظّف HTML قبل عرضه، وتغييرات الملف متاحة في التطوير المحلي.
- تتضمن قاعدة التخزين المحلية مجموعات عامة للخدمات والطلبات والعملاء والطلبات الشرائية، ويمكن استعمال دوال قاعدة البيانات المحلية معها.
- البيانات لا تنتقل بين المتصفحات أو الأجهزة ولا تظهر تلقائيًا عند فتح الموقع من جهاز آخر. مسح بيانات المتصفح يحذفها. خذ نسخة احتياطية قبل تغيير الجهاز أو المتصفح.
- مساحة `localStorage` محدودة بحسب المتصفح؛ تُقيّد صور المقال والسلايدر إلى 1 ميغابايت للصورة وتظهر رسالة عند امتلاء المساحة.
- محتوى `localStorage` خاص بالمتصفح الحالي، لذلك لا يستطيع محرك البحث قراءة المقالات المحلية أو إنشاء بيانات SEO ديناميكية لها. تبقى الصفحات العامة الأساسية قابلة للفهرسة.
- تشمل الأدوات صفحات مستقلة للسيرة الذاتية والتحليل وخطاب التقديم والمقابلات والتوجيه المهني وتنظيم طلبات العمل ومراجعة الملف المهني. تُحفظ طلبات العمل محليًا في المتصفح.
- لا تتصل الأدوات بخدمات ذكاء اصطناعي خارجية.
- إعلانات Google AdSense وخدمات الأطراف الخارجية لا تعمل دون اتصال بالإنترنت.
